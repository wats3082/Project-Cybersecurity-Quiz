# Project Cybersecurity Quiz

Modern React + TypeScript quiz experience with a standardized portfolio UI shell.

## Live site

https://wats3082.github.io/Project-Cybersecurity-Quiz/

## Features

- Topic selection + guided quiz flow
- Hint system and life indicators
- Score and end-of-game summary
- Dummy data, ready for future API-backed question bank

## Run locally

```bash
npm install
npm start
```
